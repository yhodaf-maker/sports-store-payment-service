# Contributing

Create work from `main` using one of these branch formats:

- `feature/<lowercase-kebab-case-slug>`
- `bugfix/<lowercase-kebab-case-slug>`
- `hotfix/<lowercase-kebab-case-slug>`

Open a pull request, obtain at least one approval, and use squash merge. Do not push directly to `main`. Include the related Linear issue in the pull request title or description.
